# 完整功能清单

当前 **87 项功能**。功能市场每月按实际使用排名做末位淘汰，垫底且非核心的功能会下线。

标注 **[公式]** 的项不是按钮，而是装好插件后可直接在单元格里使用的表格公式。

---

## 一、GIS 与地图（23 项）

### KML / 图层生成

| 功能 | 说明 |
|---|---|
| KML 临时打开 | 选中经纬度区域生成 KML 并在 Google Earth 中打开预览 |
| 扇区覆盖 KML | 按工参表生成扇区覆盖图层，按频段分组着色（方位角 + 波瓣宽度 + 长度） |
| 覆盖圆 KML | 按站点经纬度生成圆形覆盖图层，半径可自定义（默认 500 米） |
| 批量 KML | 导入 CSV/Excel 批量生成路测轨迹 KML |
| AOI 边界 | 按地区名搜索 AOI 边界并生成 KML，支持单次与批量 |
| WKT 转图层 | WKT 文本（Point / LineString / Polygon）转 GeoJSON / KML / SHP |
| 点坐标转点图层 | 选中经纬度生成点图层，导出 GeoJSON / KML / SHP |
| 点坐标转扇形 | 按经纬度 + 方位角 + 距离 + 波宽生成扇形图层，支持内半径环形扇区 |
| 点坐标转多边形 | 按经纬度 + 边数 + 边长生成正多边形，支持旋转角度 |
| 点坐标转星形 | 按经纬度 + 角数 + 半径生成星形，内角可调（默认五角星） |

> 生成 SHP 需要字段完整（至少经度、纬度两列在选区里），输出文件与源表同目录。

### 地图跳转

| 功能 | 说明 |
|---|---|
| 点-可收藏（奥维） | 选中经纬度一键导入奥维收藏夹，免 VIP、免 Web 接口，支持多选区合并，上限 2000 点 |
| 奥维标注圆形 | 按经纬度在奥维上画圆，列名含「半径 / 覆盖距离」时自动识别半径列 |
| 奥维清除标记 | 清除奥维地图上 TableGIS 添加的所有临时标记 |
| 奥维设置 | 配置奥维地图路径与连接参数 |
| QGIS 标注点 | 选中经纬度跳转 QGIS 并标注点 |
| QGIS 清除标记 | 清除 QGIS 中 TableGIS 添加的所有标记 |
| QGIS 设置 | 配置 QGIS 服务器地址（默认 `127.0.0.1:19871`）与坐标类型 |

### 空间匹配与量算

| 功能 | 说明 | 用在哪 |
|---|---|---|
| 单表最近点 | 计算每个点到最近 N 个站点的距离与站号（KD-Tree + Haversine） | 找周边站、核查覆盖关系 |
| 双表最近点 | 两张表按经纬度就近匹配，A 表每个点找 B 表最近站并回填属性 | 多运营商工参比对 |
| 经纬度匹配图层 | 判断点在多边形图层内 / 到图层最近距离，属性按单条 / 合并 / 展开回填 | 行政区归属、规划区判断 |
| 经纬度距离聚类 | 按缓冲距离（默认 100 米）对点分组聚类，输出组号 | 同一站址识别、去重 |
| 站间距计算 | 计算每个点到最近 N 个点（默认 3）的距离平均值作为站间距 | 站址密度评估 |
| 距离 / 方位角 | 选中 4 列（经度1,纬度1,经度2,纬度2）算两点距离与方位角，结果复制到剪贴板 | 单次快速核对 |
| 距离公式 **[公式]** | `=tablegis.DIS(经度1,纬度1,经度2,纬度2)` 返回距离（米） | 整列批量算 |
| 方位角公式 **[公式]** | `=tablegis.AZ(经度1,纬度1,经度2,纬度2)` 返回方位角（0-360°） | 整列批量算 |
| 方位角罗盘 | 悬浮罗盘，实时显示鼠标相对罗盘中心的方位角，可拖拽缩放 | 底图方位核对 |
| 海拔查询 | 选中经度、纬度两列批量查高程（米），数据源 Open-Meteo SRTM 90m | 地形起伏评估 |
| 匹配工具箱 | 上述匹配类功能的独立 exe 版，左栏切换全部功能，可多开 | 表格外独立使用 |

## 二、坐标与地址（7 项）

| 功能 | 说明 |
|---|---|
| 地址经纬度互转 | 批量地址 ↔ 经纬度互转（支持逆地理），双列互填，切换方向保留原有内容 |
| GPS 转百度 | WGS84 → 百度 BD09 |
| GPS 转高德 | WGS84 → 高德 GCJ02 |
| 高德转 GPS | GCJ02 → WGS84 |
| 百度转 GPS | BD09 → WGS84 |
| 十进制转度分秒 | `116.3975` → `116°23′51″` |
| 度分秒转十进制 | `116°23′51″` → `116.3975` |

> 为什么需要转换：手机 GPS 记录的是 WGS84，高德地图用的是 GCJ02，百度地图用的是 BD09。同一个地点，三种坐标在图上相差 300-500 米。**混用算距离是表格地理数据最常见的错误。**

## 三、数据工具（全行业通用，9 项）

| 功能 | 说明 |
|---|---|
| 多 sheet 合并 | 全部工作表合并成一张总表，字段一致自动对齐，不一致自动新增列 |
| 两列对比 | 选中两列（可整列）找出各自独有的值并自动标色（浅红 / 浅黄） |
| 按列拆分 | 选中拆分依据列，按值把整表拆成多个工作表，空值单独成表 |
| 身份证解析 | 批量提取生日 / 性别 / 年龄 / 省份，并校验真伪 |
| 手机号校验 | 批量校验号码、识别运营商、一键脱敏打码 |
| 正则提取 | 批量提取数字 / 中文 / 英文 / 邮箱 / 手机号 / 网址 / 身份证号 |
| 日期转换 | 乱格式日期统一转标准日期（`2026.1.5` → `2026-01-05`），附星期 / 季度 / 年月 |
| 金额大写 | 数字金额一键转人民币大写（壹佰贰拾元整），支持负数 |
| 数据生成 | 批量生成随机姓名 / 手机号 / 邮箱 / 身份证 / 整数 / 小数 / 日期 |

> 身份证列建议先设为**文本格式**再操作，否则 Excel 会把它当数字导致末位精度丢失。

## 四、数据清理（5 项）

| 功能 | 说明 |
|---|---|
| 提取唯一值 | 从选中区域提取不重复的唯一值，结果复制到剪贴板 |
| 删除前后空白 | 删除值前后的空格、Tab、全角空格、换行 |

## 七、文件工具（7 项）

处理**文件夹**而不是表格内容的功能，常用在批量归档场景。

| 功能 | 说明 |
|---|---|
| 批量重命名 | 序号模式（前缀 + 3 位序号），或**清单模式**：Excel 两列写「旧文件名」「新文件名」，按清单改名，支持预览与撤销 |
| 文件清单导出 | 文件夹内所有文件导出成表格（文件名 / 大小 / 修改日期），支持递归子目录，导出 CSV 或直接进剪贴板 |
| 图片批处理 | 批量压缩、转格式、限制最大宽度、加文字水印（JPG / PNG / BMP） |
| PDF 合并 | 多个 PDF 按顺序合并，可拖动调整次序 |
| PDF 拆分 | 按页拆成单页文件（`文件名_001.pdf` …），输出到源文件所在目录 |
| 图片转 PDF | 多张图片合并成一个 PDF，JPG 直接嵌入不重压缩不损画质，可拖动调页序 |
| 导出 PDF | 当前工作簿一键另存为 PDF（保存到表格同目录），走自带导出引擎 |

## 八、单位转换（14 项）

**功率（2）**：dBm ↔ W（`W = 10^((dBm-30)/10)`）

**进制（6）**：2 / 8 / 16 进制 ↔ 10 进制，双向互转

**速率（6）**：Gbps / Mbps / Kbps / MB/s 互转（注意 MB/s 与 Mbps 是 8 倍关系，不是 1000）

## 功能市场

插件内置**功能市场**：所有功能按分类列出，可以按名称、说明、拼音搜索，能看到每个功能的**实际使用次数**，支持把常用功能拖到顶部的自定义工作台。

因为功能是每周上新、每月淘汰的，所以列表会变——以插件里看到的为准。
