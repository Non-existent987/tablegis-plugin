# 安装与激活

## 系统要求

| 项目 | 要求 |
|---|---|
| WPS Office | 2019 及以上（WPS 表格） |
| Microsoft Excel | 2013 及以上（32/64 位均可） |
| .NET Framework | 4.7.2（Excel 版需要，Win10/11 一般自带） |
| 操作系统 | Windows 7 SP1 及以上 |
| 网络 | 激活与更新需要联网，日常使用可离线 |

> WPS 的 Mac 版不支持加载项机制，TableGIS 仅支持 Windows 版。

---

## 安装步骤

1. 到官网下载安装包：<https://www.tablegis.com>
   - **WPS 版** 与 **Excel 版**是两个安装包，按你实际用的软件下载；
   - 两个都装也没问题，互不冲突。
2. 关闭 WPS / Excel（安装程序需要写入加载项目录，开着会失败）。
3. 双击安装包，一路「下一步」。默认装在 `%APPDATA%` 用户目录下，**不需要管理员权限**。
4. 打开 WPS 表格或 Excel，顶部多出一个 **TableGIS** 选项卡，说明装好了。

### 安装后看不到选项卡

按顺序排查：

1. **确认软件已完全重启** —— 安装完必须关掉所有 WPS/Excel 窗口重新打开，加载项只在启动时加载。
2. **WPS 用户**：`工具` → `开发工具` → `加载项`，确认 TableGIS 在列表里且未被禁用。
3. **Excel 用户**：`文件` → `选项` → `加载项` → 底部「管理：Excel 加载项」→ 转到，确认勾选了 TableGIS。
4. **被安全软件拦了**：部分国产安全软件会把加载项 DLL 当可疑文件，加白名单或先退出再装。
5. 还是不行，把安装目录下的日志（`license.log`）发给作者，或在群里问。

## 激活

首次安装后有 **30 天免费试用期**，试用期内全部功能可用，不需要激活。

试用到期后点选项卡上的「激活插件」：

1. 弹窗里会显示你机器的**硬件指纹**（形如 `hw_xxxxxxxxxxxx`），点「复制」；
2. 把这个指纹发给作者（邮箱 / 微信），购买后拿到授权码；
3. 在弹窗里输入授权码，点激活，提示成功即可。

**授权码与硬件绑定**。换电脑、重装系统导致指纹变化时，把新旧指纹一起发过来，可以免费迁移。

### 常见激活问题

| 现象 | 原因与处理 |
|---|---|
| 提示「授权码已被使用」 | 授权码已绑定了另一台机器。联系作者处理迁移 |
| 硬件变化后提示未激活 | 换硬件/重装系统导致指纹变了，发送新指纹做迁移 |
| 提示网络错误 | 检查能否访问 `www.tablegis.com`；公司内网如有代理需要放行 |
| 显示剩余天数但功能不可用 | 多为系统时间异常，校准系统时间后重新激活 |
| 之前能用、突然提示过期 | 先确认是否已到期；未到期联系作者查授权状态 |

## 更新

点选项卡上的 **「更新」** 按钮，插件会自动对比服务器上的最新版本：

- 有新版：弹窗提示，点确认自动下载安装，装完重启表格软件；
- 已是最新：提示后关闭。

也可以随时到官网手动下载最新安装包覆盖安装，**授权信息不会丢失**。

更新通道支持双域名，主域名异常时会自动切换备用域名，避免更新失败。

---

## 卸载

**WPS 版**：`控制面板` → `程序和功能` → 找到 TableGIS → 卸载

**Excel 版**：同样在控制面板卸载

卸载不会影响你的表格文件。授权信息保留在服务器，重装后仍然有效。

---

## 离线使用

- **日常功能**：完全离线可用（距离方位角、坐标转换、数据清洗、文件工具等）。
- **需要联网的功能**：海拔查询、地址经纬度互转、翻译、AOI 边界、更新检查。
- **授权验证**：客户端会不定期联网校验，长时间离线会走本地兜底（7 天时效），联网后自动恢复。
