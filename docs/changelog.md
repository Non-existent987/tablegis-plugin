## 关于版本号

- WPS 版与 Excel 版**共用同一个版本号**，构建号可能不同；
- 检查更新时会对比构建号，不需要手动记版本。

## 功能调整说明

插件执行**末位淘汰制**：每月统计各功能的实际使用次数，排名垫底且非核心的功能会被合并或下架。

这意味着「更新日志里出现功能下线」是正常现象，不是 bug。目的是让功能市场保持精炼，而不是越堆越臃肿。被下线功能的用户如有需要，可在群里提出恢复。
