# 表格公式：在单元格里直接算经纬度距离和方位角

TableGIS 装好后，WPS 表格和 Excel 里会多出两个自定义公式。**不用导数据、不用写脚本、不用开 QGIS**，直接在单元格里写：

```
=tablegis.DIS(经度1, 纬度1, 经度2, 纬度2)      两点地表距离，单位：米
=tablegis.AZ(经度1, 纬度1, 经度2, 纬度2)       方位角，0-360°，正北为 0°，顺时针
```

和 `SUM`、`VLOOKUP` 一样用，支持引用单元格、下拉填充、双击填充柄。

---

## 距离怎么算？一个例子

假设 A 列是「站点经度」，B 列是「站点纬度」，C、D 列是另一个点：

| | A | B | C | D | E |
|---|---|---|---|---|---|
| 1 | 经度1 | 纬度1 | 经度2 | 纬度2 | 距离(米) |
| 2 | 116.3975 | 39.9087 | 121.4737 | 31.2304 | `=tablegis.DIS(A2,B2,C2,D2)` |
| 3 | 113.2644 | 23.1291 | 114.0579 | 22.5431 | `=tablegis.DIS(A3,B3,C3,D3)` |

在 E2 写下公式，回车得到 `1068138.87`（北京到上海，约 1068 公里），然后下拉填充整列。

**算每个站点到某个固定点的距离**（比如到市中心），把固定的那个点写成常量或绝对引用即可：

```
=tablegis.DIS(A2, B2, 116.3975, 39.9087)
=tablegis.DIS(A2, B2, $J$1, $K$1)          ← 引用固定点单元格
```

再配合筛选或排序，一秒钟找出「距离中心点 500 米内的所有站点」。

## 方位角怎么用？

```
=tablegis.AZ(A2, B2, C2, D2)
```

返回 0-360 的数值：0°=正北，90°=正东，180°=正南，270°=正西。

典型场景：

- **天线朝向核对**：工参表里有「方位角」列，算出来的实际方位角和填写值差多少，一眼看出装反的站。
- **扇区图验证**：生成的扇区图朝向不对时，先用公式定位是哪几个站的数据有问题。
- **路测方向判断**：判断轨迹是朝着基站还是背离基站。

配合 `ROUND` 取整更清爽：

```
=ROUND(tablegis.AZ(A2,B2,C2,D2), 1)
```

## 参数说明

| 参数 | 含义 | 格式 |
|---|---|---|
| 经度1 / 经度2 | 起止点经度 | 十进制度，东经为正（如 `116.3975`），西经为负 |
| 纬度1 / 纬度2 | 起止点纬度 | 十进制度，北纬为正（如 `39.9087`），南纬为负 |

**注意：经度在前，纬度在后。** 这是地理行业的通用顺序（GeoJSON、KML、PostGIS 都这么写），和平时口头说的「北纬多少东经多少」相反，别填反了。

---

## 算法说明

- **距离**：Haversine 球面距离，地球半径取 6371000 米，与 Google Earth、QGIS 的 `$length` 同源算法。
- **方位角**：大圆初始方位角（标准 `atan2` 公式），与 GIS 软件一致。
- 完整实现已开源：[`core/`](../core/)，JS / C# / Python 三种语言版本。

## 常见问题

**公式打不出来 / 提示 `#NAME?`**

1. 确认插件已安装且选项卡已出现在 WPS 或 Excel 里；
2. 公式名不区分大小写，`=tablegis.dis(...)` 一样有效；
3. 是英文句点 `.` 不是中文句号 `。` —— 这是最常见的低级错误；
4. 中文输入法下写的括号可能变成全角括号 `（）`，需要改成半角 `()`。

**结果是 0 或者离谱的大数字**

多半是经度和纬度填反了。检查参数顺序：**经度、纬度、经度、纬度**。

**算出来的距离和百度地图测的不一样**

十有八九是坐标系没统一。百度地图用的是 BD09，手机 GPS 录的是 WGS84，同一地点差 300-500 米。先把坐标转成同一个系再算（插件里有「GPS转百度」「百度转GPS」等一键转换功能），或者直接用表格里的换算功能批处理。

**长距离算方位角和地图上量的角度不一样**

方位角会沿大圆变化。北京到上海算出的 153° 是出发时的朝向，越往东南飞朝向越偏。几百米范围不会有这个问题。

**能批量算几万行吗？**

可以。公式是纯计算，不联网。几万行下拉填充会有一两秒的计算时间，属正常。
